# Interface font sources

- Noto Sans SC: Google Fonts `ofl/notosanssc/NotoSansSC[wght].ttf`, compressed to WOFF2 without outline changes. Its reserved name is Source; the supplied family is Noto Sans SC.
- Lora: unmodified official Latin variable WOFF2 from Google Fonts.

Lora source: https://fonts.gstatic.com/s/lora/v37/0QIvMX1D_JOuMwr7Iw.woff2

Lora SHA-256: `ddb8c66035104e233fc024669183aad3738b6daa16deee2ebb1241bd0f98ace1`

The adjacent OFL files retain the original copyright and license texts. All font assets are embedded locally; application use makes no font-provider request.
