# Third-party notices and references

Ycscite uses the Rust crates locked in native/Cargo.lock. Portable releases contain a dependency/license inventory and available license texts under licenses/. The packaged Java runtime retains its license files under runtime/legal/. Windows WebView2 is a system runtime.

The logo was supplied for this project. Original CiteSpace binaries, decompiled sources, research data, private reference screenshots and historical journal basemaps are not part of this distribution.

The local bibliometric-miner research was inspected for extension ideas. No code from that project has been incorporated into the default nine-chart renderer. Its original project is wuwr5/bibliometric-miner (MIT, copyright2026wuwr5); any future code reuse must retain its corresponding license and attribution. Current optional Equivalence similarity follows the explicitly documented mathematical formula.

Method references and the precise implemented definitions are in docs/CAPABILITIES.md. Ycscite is a separate project and does not distribute CiteSpace or claim official affiliation.

The interface embeds Noto Sans SC and Lora from the Google Fonts distribution, under the SIL Open Font License 1.1. An unmodified official Lora WOFF2, the compressed Noto Sans SC WOFF2, and their license texts are stored in `native/web/fonts/`; portable releases include both license texts. Noto Sans SC is the Chinese/Latin UI family; Lora is used for the Latin wordmark and headings. The product retains the user-provided Ycscite logo.
