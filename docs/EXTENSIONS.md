# 参考工程能力对照与扩展边界

用户确认：Ycscite 九图保持现有画法。参考工程用于识别平台能力缺项；可选扩展不替换九图绘制，不修改默认算法、布局或配色。

本次核对的是 `wuwr5/bibliometric-miner` 的本地研究快照，Git 提交 `485d2b40d62fbedfa1e0cf63123cd3be236f66c0`。原工程 MIT 许可，版权归原作者；若将来复用代码，应保留其许可与来源。当前仅吸收功能思路和公开数学定义，没有复制其交互绘图代码进入九图。

## 源码核对中需要保留的判断

- 预测源码会按末年低于此前三年中位数一半自动剔除末年。这可能误删真实下降；平台若实现，应让用户明确选择末年完整性，并同时保留原始年度数据。
- 预测区间当前是回测误差和模型分歧组成的探索性范围，不能未经校准就当作具有给定覆盖率的置信区间。
- 结构变异源码的说明存在不同的 delta-M 符号叙述，分区固定和重新聚类也有不同含义。应按明确的数学定义和可复现小图验证，不能照 README 的名称直接宣称方法等价。
- c-TF-IDF 式管线不等同于完整 BERTopic；网络社区不等同于概率主题模型。
- 所有后续扩展都应能在 CLI/headless 中调用，并有结构化结果、数据条件说明及验证用例。
