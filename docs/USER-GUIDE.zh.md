# 使用指南

1. **导入文献**：选择目录、选择文件或拖入文件；也可点击「使用示例」。导入后核对文献数、年份和参考文献覆盖。
2. **选择要做的图**：中央顶部直接选择关键词共现、聚类、时区、时间线、作者合作等任意一图。扩展图从「更多视图」选择。
3. **设置参数**：左侧可直接改年份、切片、节点选择、剪枝和聚类。作者与机构视图会显示对应的固定分析对象；扩展视图可切换网络类型。
4. **运行当前图**：点击「运行分析」。一次只生成选中的视图。换图后可独立运行，切回已生成的图可以继续查看。
5. **读图与核查**：右侧显示与当前视图对应的网络指标、高频节点和解释；点击节点查看频次、中心性和聚类编号。点击「数据表」查看、搜索并下载完整数据。
6. **导出**：PNG 导出当前图；PDF 导出该次运行的图册；SVG 是分析网络总览，选择器会注明范围。Logo 开关使用预生成版本，不改变图中数据。

「批量导出」是单独的操作：勾选自己需要的图和格式，再运行。没有固定四图组合。CLI 的 `analyze` 默认只生成网络总览；`report` 仍可一键生成完整九图，两者都可用 `--charts` 指定任意图。

修改参数后，已有图会标记「待更新」，以免把旧结果当成新结果。确认参数后再次运行当前图。「项目结果」可恢复历史参数和结果；「打开项目结果」可打开已保存的报告目录。

## 参数与数据

「分析设置」按数据、网络、聚类与突现、导出设置、附加分析分类。设置可保存为 JSON，在 CLI/headless 中复用。关闭对话框会放弃尚未应用的修改。每次运行会保存 `settings.json` 和 `manifest.json`。

默认结果位于本机用户数据目录的 `Ycscite/reports`；Windows 为 `%LOCALAPPDATA%/Ycscite`。Web / EXE 将所选保存位置作为父目录，每次运行创建独立子目录，保留不同参数版本。CLI / headless 的输出路径仍是实际报告目录，显式复用同一路径会更新同名文件。清单只列出本次生成的图。

- **词和连线太多**：降低 g-index k，或改用 Top N；选择 MST / Pathfinder 剪枝。字号只改变显示，不能减少网络规模。
- **标签太挤**：在导出设置中减少主要标签数量，调整字号、节点大小与连线不透明度。
- **排除无意义词**：在聚类与突现页填写排除词，支持逗号、分号或换行；匹配不区分英文字母大小写。
- **共被引和耦合**：需要原始参考文献字段。缺少关键词时，可以在扩展视图选择题名 / 摘要术语网络。
- **热力图**：每行是聚类，每列是年份，颜色是原始词项频次。所有单元格共用线性色标。完整数据见 `cluster-activity.tsv`。
- **山峰图**：各行按自身峰值归一化。跨簇比较绝对数量时读取原始数据表。
- **t-SNE / UMAP**：用于结构探索，不能据距离直接断言语义相似。t-SNE 困惑度、迭代次数、UMAP 近似布局迭代次数与随机种子可在导出设置中修改。
- **期刊引文流**：仅使用可解析的施引与被引期刊。缺少参考文献时显示说明，不会把关键词补作被引期刊。这不是 JCR 学科底图双图叠加。
- **英文结果**：切换 English 后重新运行；界面、图题和坐标用英文，文献内容保留原文。
- **手工编辑**：打开「高级交互窗口」：已有当前结果时恢复对应的可编辑项目；参数有变更时按当前参数分析。节点编辑、标注和书签可在该窗口另行保存为项目，已导出的图不被修改。
- **停止分析**：终止本次子进程；部分文件可能保留，但不会显示为完整结果。

## 关闭与恢复

语言、参数、输入路径、结果保存位置、当前视图、图谱/数据表页、所选结果与 Logo 选择会自动写入本机工作区。顶部显示保存中、已保存或更改未保存；确认已保存后关闭即可。重开会恢复工作区，**不会自动重新计算**。保存失败时仍可继续查看已有结果，并通过「保存参数 JSON」保留配置。

工作区文件为本机数据目录中的 `workspace.json`，包含本机路径，不是供 CLI 使用的参数文件。不要把它作为公开项目资料提交。Windows 默认目录为 `%LOCALAPPDATA%/Ycscite`；Linux 为 `$XDG_DATA_HOME/Ycscite` 或 `~/.local/share/Ycscite`；macOS 为 `~/Library/Application Support/Ycscite`；可通过 `YCSCITE_DATA_HOME` 指定位置。损坏的工作区会保留恢复副本，不会删除已生成报告。

重新导入或重开时会核对解析后的文献数据。源文件在同一路径被修改，也会提示「源数据已修改」。旧图可继续查看或导出，但会标为历史结果，直到重新运行。旧版本报告未记录数据身份时，也不会被当成已核实的当前结果。

## 保存可编辑结果与记录

导出格式中选择「可编辑项目」，可下载当前关键词、作者、机构或扩展网络对应的 `.csl-proj` 文件。它包含本次纳入的文献、节点、连接、聚类、指标及完整分析参数，离开原始文件目录也能在高级窗口恢复。报告目录下 `projects/` 保存各网络的项目文件；离线报告页也有下载链接。

高级窗口保存项目会保留节点书签、批注、自定义名称与其他中心性数值，切换界面语言也保留当前分析。重新运行会按参数重建网络；需要保留手工编辑时先另存项目。原始未纳入的文献不在项目中；原始文件仍是重新选择其他年份或恢复已排除记录的依据。

记录级 `records.tsv` 使用版本标记与多值字段 JSON 数组，避免把机构、作者和参考文献中的分号当作分隔符，或抹掉文本中的换行。新旧 Ycscite TSV 均可导入。报告清单分别记录原始数据和实际纳入数据的身份。

标注词源 K 使用所选标注算法；T/A/WC/R/TKA 等文档词源目前使用文档级 LLR。参数选择与算法实际定义应一并记录，不能把这理解为所有标注算法和词源均可任意组合。

高级窗口中的「标准九图报告」是独立的文件导入与标准预设流程，按当前界面语言生成并创建独立结果子目录；需要逐图、自定义参数时使用主工作台的相应视图。
